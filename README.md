# MD-Quick-Move
Obsidianでデータを任意ディレクトリに1ボタンで移動させることができるプラグイン

# 注意事項

**すべてClaudeCodeによる生成**

# 機能
ファイルを開いた画面の右上に移動ボタンを追加<br>
設定画面で移動先（表示名とフォルダパス）を複数登録し、並べ替え可能<br>
Markdown、Canvas、画像、PDF など、開けるファイルすべてに対応<br>
移動時に内部リンクを自動更新（Obsidian の設定「内部リンクを常に更新」に従う）<br>

# インストール方法
下の main.js、manifest.json、styles.css をダウンロード<br>
Vault の .obsidian/plugins/md-quick-move/ に入れる<br>
［設定 → コミュニティプラグイン］で「MD-Quick-Move」を有効にする<br>

# 動作環境
Obsidian 1.4.10 以上<br>
デスクトップ専用（モバイル非対応）<br>

# 不具合
* 特になし
